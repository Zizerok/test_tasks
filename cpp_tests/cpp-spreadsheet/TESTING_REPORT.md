В методе Cell::Clear() содержимое ячейки очищается, но связи между ячейками не удаляются и кэш зависимых формул не сбрасывается. Поэтому после удаления A1 в B1 может остаться указатель на уже освобождённую ячейку, что приводит к heap-use-after-free, а другие формулы продолжают возвращать старое значение из кэша. Также пустая ячейка, созданная как ссылка из формулы, ошибочно увеличивает печатную область таблицы.

Для исправления при очистке ячейки нужно сначала сбросить кэш всех зависимых формул, удалить эту ячейку из списков зависимостей связанных ячеек и только после этого удалять её объект. В GetPrintableSize() следует учитывать только ячейки с непустым текстом, чтобы служебные пустые ячейки не влияли на размер области печати.
