## 1. Открытие смены

По умолчанию: будущая дата, время `09:00–18:00`, одна организация. Свободная позиция добавлена кнопкой «Добавить позицию».

| ID | Тип | Сценарий | Статус |
| --- | --- | --- | --- |
| OPEN-01 | Положительный | Создание смены с одним свободным местом без назначенных сотрудников | Not run |
| OPEN-02 | Положительный | Создание смены с двумя свободными должностями: 2 места по первой и 3 по второй | Not run |
| OPEN-03 | Положительный | Создание смены с одним назначенным сотрудником и одним свободным местом | Not run |
| OPEN-04 | Негативный | Сохранение смены без назначенных сотрудников и свободных позиций | Not run |
| OPEN-05 | Положительный | Создание свободной позиции со 100 местами — верхней границей формы Qt | Not run |
| OPEN-06 | Негативный | Попытка создания свободной позиции с количеством мест `0` | Not run |
| OPEN-07 | Негативный | Попытка создания свободной позиции с количеством мест `101` | Not run |
| OPEN-08 | Негативный | Сохранение смены с одним свободным местом и интервалом `09:00–09:00` | Not run |
| OPEN-09 | Негативный | Быстрое двойное нажатие «Сохранить смену» в заполненной форме | Not run |
| OPEN-10 | Негативный | Сбой записи второй свободной позиции после вставки смены и первой позиции в одной транзакции | Not run |

Эндпоинт: `POST /api/send-shift-notification`. По умолчанию: существующая смена, непустой текст, корректный получатель, одна свободная должность.

| ID | Тип | Сценарий | Статус |
| --- | --- | --- | --- |
| SEND-01 | Положительный | Отправка уведомления одному сотруднику | Not run |
| SEND-02 | Положительный | Рассылка уведомления двум сотрудникам | Not run |
| SEND-03 | Положительный | Отправка уведомления с двумя свободными должностями одному сотруднику | Not run |
| SEND-04 | Положительный | Отправка уведомления назначенному сотруднику с `open_positions = []` | Not run |
| SEND-05 | Негативный | Отправка запроса с пустым списком получателей `user_ids = []` | Not run |
| SEND-06 | Негативный | Отправка уведомления с несуществующим `shift_id` | Not run |
| SEND-07 | Негативный | Отправка запроса без обязательного поля `message` | Not run |
| SEND-08 | Негативный | Отправка запроса с `user_ids = ["abc"]` | Not run |
| SEND-09 | Негативный | Обращение к эндпоинту рассылки без авторизации | Not run |
| SEND-10 | Негативный | Отправка уведомления с недействительным токеном сообщества VK | Not run |
| SEND-11 | Негативный | Рассылка двум сотрудникам, когда первый запретил сообщения сообщества, а второй разрешил | Not run |
| SEND-12 | Негативный | Превышение времени ожидания ответа VK при отправке одному сотруднику | Not run |
| SEND-13 | Негативный | Сбой записи в `sent_notifications` после успешной отправки сообщения через VK | Not run |
| SEND-14 | Негативный | Отправка уведомления с `message = ""` | Not run |

## 3. Отклик первого сотрудника

Эндпоинт: `POST /vk/callback`, тип payload — `shift_response`. По умолчанию: активный сотрудник подходящей должности, одно свободное место, верный `secret`, назначений нет.

| ID | Тип | Сценарий | Статус |
| --- | --- | --- | --- |
| RESP-01 | Положительный | Отклик на последнее свободное место с payload в виде JSON-объекта | Not run |
| RESP-02 | Положительный | Отклик на должность, доступную сотруднику через `position_capabilities` | Not run |
| RESP-03 | Положительный | Отклик с payload в виде строки, содержащей корректный JSON-объект | Not run |
| RESP-04 | Негативный | Отклик сотрудника неподходящей должности без разрешённого замещения | Not run |
| RESP-05 | Негативный | Отклик неактивного сотрудника | Not run |
| RESP-06 | Негативный | Отклик пользователя с VK ID, отсутствующим в списке сотрудников | Not run |
| RESP-07 | Негативный | Отклик сотрудника другой организации, не зарегистрированного в организации смены | Not run |
| RESP-08 | Негативный | Отклик сотрудника, уже назначенного администратором на эту смену, при наличии свободного места | Not run |
| RESP-09 | Негативный | Повторная доставка идентичного callback с тем же `event_id` после успешного отклика | Not run |
| RESP-10 | Негативный | Отклик на смену, удалённую после получения уведомления | Not run |
| RESP-11 | Негативный | Отклик без поля `payload.position` | Not run |
| RESP-12 | Негативный | Отклик с неверным `secret` при настроенном непустом `VK_SECRET_KEY` | Not run |
| RESP-13 | Негативный | Отклик без поля `secret` при настроенном непустом `VK_SECRET_KEY` | Not run |
| RESP-14 | Негативный | Передача callback с `object = null` | Not run |
| RESP-15 | Негативный | Передача callback с синтаксически некорректным JSON в теле запроса | Not run |
| RESP-16 | Негативный | Отказ VK при отправке списка смен после фиксации успешного отклика в БД | Not run |
| RESP-17 | Негативный | Получение истории через `GET /api/shift-responses` без авторизации при наличии откликов двух организаций | Not run |
| RESP-18 | Негативный | Сбой записи в `activity_logs` после создания назначения и отклика, до фиксации транзакции | Not run |
| RESP-19 | Положительный | Отклик на свободное место с почасовой оплатой 500 ₽/ч | Not run |
| RESP-20 | Негативный | Отклик через ранее полученное уведомление на смену со статусом «Отменена» | Not run |

## 5. Отмена смены сотрудником

Эндпоинт: `POST /vk/callback`, тип payload — `cancel_shift`. Отмена снимает назначение сотрудника и возвращает место в набор, сама смена сохраняется.

| ID | Тип | Сценарий | Статус |
| --- | --- | --- | --- |
| CANCEL-01 | Положительный | Отмена своего назначения при отсутствии свободной позиции этой должности | Not run |
| CANCEL-02 | Положительный | Отмена своего назначения при наличии одного свободного места той же должности | Not run |
| CANCEL-03 | Негативный | Повторная доставка идентичного callback отмены после успешного снятия назначения | Not run |
| CANCEL-04 | Негативный | Отмена назначения пользователем, который не назначен на выбранную смену | Not run |
| CANCEL-05 | Негативный | Отмена назначения в смене другой организации с подменой `payload.shift_id` | Not run |
| CANCEL-06 | Негативный | Сбой восстановления свободной позиции после удаления назначения в той же транзакции | Not run |
| CANCEL-07 | Негативный | Одновременная отмена одного назначения двумя идентичными запросами | Not run |
| CANCEL-08 | Положительный | Отклик второго сотрудника на место, освобождённое первым после отмены назначения | Not run |
| CANCEL-09 | Негативный | Одновременная отмена назначения первым сотрудником и отклик второго на эту должность при отсутствии других мест | Not run |
| CANCEL-10 | Положительный | Отмена назначения с почасовой оплатой 500 ₽/ч при отсутствии свободной позиции этой должности | Not run |
| CANCEL-11 | Положительный | Отмена своего назначения в смене с двумя назначенными сотрудниками | Not run |
| CANCEL-12 | Положительный | Повторный отклик сотрудника после отмены собственного назначения на эту смену | Not run |
| CANCEL-13 | Негативный | Отмена своего назначения с подменой `payload.position` на должность другого назначенного сотрудника | Not run |
